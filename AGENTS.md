# Agent Instructions

Every agent working in this repository must follow the project development skill:

- Read and apply `.agents/skills/project-development/SKILL.md` before inspecting or changing project code.
- Read and apply `.agents/skills/karpathy-guidelines/SKILL.md` before planning or implementing changes.
- Treat the existing implementation as the source of truth and preserve the documented architecture, API response contract, error codes, validation, authentication, rate limiting, SeaORM, and OpenAPI rules in that skill.
- Report verification results accurately and do not modify unrelated worktree changes.
